🔑 4. Bakış Açısı: Dinamik QR & Turnike Geçiş Akışı
HMAC SHA-256 imzalı kısa ömürlü QR üretimi, Scanner PWA offline-ready doğrulaması, JTI replay saldırı koruması ve turnike kapı rölesi sinyali.

⚡ Kriptografik QR ve Donanım Geçiş Sıralaması

Milisanilerde güvenli doğrulama ve replay koruması.

sequenceDiagram
  autonumber
  actor Member as 👤 Member (Mobile App)
  participant Gateway as ⚡ API Gateway (:8000)
  participant AccessService as 🔑 Access Engine
  actor Kiosk as 📹 Kiosk Scanner PWA (:5174)
  actor Turnstile as 🚪 Turnstile Relay

  rect rgb(15, 23, 42)
  note over Member, AccessService: A. Dynamic QR Generation Phase
  Member->>Gateway: POST /api/v1/qr/issue-self (Bearer JWT Token)
  Gateway->>AccessService: Generate Dynamic Short-Lived QR
  AccessService->>AccessService: Sign HMAC-SHA256 (kid: qr-202608, exp: +300s, unique JTI)
  AccessService-->>Gateway: Dynamic QR JWT Token
  Gateway-->>Member: Render QR Visual on App Screen
  end

  rect rgb(11, 15, 25)
  note over Member, Turnstile: B. Turnstile Scanning & Hardware Access Phase
  Member->>Kiosk: Present QR Code to Camera Scanner
  Kiosk->>Gateway: POST /api/v1/devices/qr/validate (Device Session + QR Token)
  Gateway->>AccessService: 1. Validate Signature (kid)
2. Check Expiration (exp)
3. Check Replay Cache (JTI)
4. Check Entitlement Wallet (GYM_ENTRY)
  end

  alt 🟢 ACCESS GRANTED (Valid & Entitled)
    AccessService->>Gateway: Result: GRANTED (Checkin Recorded)
    Gateway-->>Kiosk: granted: true, checkin_id
    Kiosk->>Turnstile: ⚡ Trigger Relay Pulse (Door Opens)
    Kiosk-->>Kiosk: Render GREEN Screen: "Hoşgeldiniz!"
  else 🔴 ACCESS DENIED (Replay / Expired / No Entitlement)
    AccessService->>Gateway: Result: DENIED (Reason: REPLAY_ATTACK)
    Gateway-->>Kiosk: granted: false, reason: "REPLAY_ATTACK"
    Kiosk-->>Kiosk: Render RED Screen: "Geçersiz / Kullanılmış QR!"
  end
