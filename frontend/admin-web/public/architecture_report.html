🔑 4. Bakış Açısı: Dinamik QR & Turnike Geçiş Akışı 🟡 PARTIAL (Logic Live / Hardware Target)
Compact 2-part HMAC-SHA256 kısa ömürlü QR (Default 60s TTL), Scanner PWA (Staff Session + Device Endpoint Fallback), JTI replay koruması ve Target Turnstile Relay.

⚡ Kriptografik QR ve Donanım Geçiş Sıralaması

Compact HMAC Token: base64url(payload).base64url(sig). Key format: qr-202608-x9a1. Default 60s TTL.

sequenceDiagram
  autonumber
  actor Member as 👤 Member (/member Route)
  participant Gateway as ⚡ API Gateway (:8000)
  participant AccessService as 🔑 Access Engine (app/services/access.py)
  actor Kiosk as 📹 Kiosk Scanner PWA (:5174)
  actor Turnstile as 🚪 Turnstile Relay 🔵 TARGET

  rect rgb(15, 23, 42)
  note over Member, AccessService: A. Dynamic Compact HMAC QR Generation Phase
  Member->>Gateway: POST /api/v1/qr/issue-self (Secure HttpOnly Session Cookie)
  Gateway->>AccessService: Generate Short-Lived QR (Default 60s TTL)
  AccessService->>AccessService: Sign HMAC-SHA256 (kid: qr-202608-a9f1, exp: +60s, unique JTI)
  AccessService-->>Gateway: Compact Token: base64url(payload).base64url(sig)
  Gateway-->>Member: Render Dynamic QR Visual on Member Portal
  end

  rect rgb(11, 15, 25)
  note over Member, Turnstile: B. Turnstile Scanning & Access Verification Phase
  Member->>Kiosk: Present QR Code to Camera Scanner
  Kiosk->>Gateway: POST /api/v1/devices/qr/validate (Device Session or Staff Session Fallback)
  Gateway->>AccessService: 1. Validate Signature (kid)
2. Check Expiration (Default 60s)
3. Check Replay Cache (JTI in QrJtiReplay)
4. Check Entitlement Wallet (EntitlementService)
  end

  alt 🟢 ACCESS GRANTED (Valid & Entitled)
    AccessService->>Gateway: Result: GRANTED (Checkin Recorded in DB)
    Gateway-->>Kiosk: granted: true, checkin_id
    Kiosk-->>Kiosk: Render GREEN Screen: "Geçiş Onaylandı" ✅
    Kiosk-.->Turnstile: ⚡ Trigger Hardware Relay Pulse 🔵 TARGET
  else 🔴 ACCESS DENIED (Replay / Expired / No Entitlement)
    AccessService->>Gateway: Result: DENIED (Reason: REPLAY_ATTACK / EXPIRED)
    Gateway-->>Kiosk: granted: false, reason
    Kiosk-->>Kiosk: Render RED Screen: "Geçersiz / Kullanılmış QR!" ✅
  end

🛡️ Architecture Implementation & Target Compliance Matrix
Tenancy & Isolation Tier ✅ IMPL / 🔵 TARGET

Gym = Tenant boundary. Live: Shared DB + RLS via get_tenant_id(). Target: IsolationProvider abstraction for Dedicated Schema/DB.

Identity & Membership ✅ IMPLEMENTED

User != Member, Federation != Tenant, Branch = Location strictly enforced. Member Portal is /member route in admin-web.

Financial Ledger & PCI ✅ IMPLEMENTED

Integer math via amount_minor (Kuruş/cents). Zero raw PAN/CVV card data stored or logged.

Turnstile Security Gate 🟡 PARTIAL

Compact HMAC-SHA256 QR + Default 60s expiry + JTI Replay Prevention + Scanner PWA UI. Physical Relay Pulse is Target.

Transactional Outbox 🟡 PARTIAL

Atomic DB outbox live in ReportService.request_run with SKIP LOCKED poller. NATS event bus is Target transport.

Data Retention & Lifecycle 🔵 TARGET

11-stage tenant lifecycle machine and Data Retention Engine are specified in MASTER_SPEC 129/130 as target architecture.
